# Phrasync 0.4.5

A bigger local editing workspace, with more control over your video and export.

- A media bin and up to four background tracks for images, videos and built-in 2D/3D visuals. Drag, trim, split, duplicate and remove clips; mix them with opacity, fades, wipes and slides. Track removal keeps original media in the bin.
- Pan/zoom, black-and-white, gradients, particles and an audio-reactive spectrum. Beat or transient triggers for shake, pendulum motion, flashes, drop zoom and light pulses.
- Spiral Flight and Word Constellation text animation in 2D and 3D.
- Export IN/OUT with I/O, draggable markers or exact seconds. Render just the selected interval, including correctly positioned audio, footage, text and effects. Automatic or custom timeline duration.
- Timeline zoom anchored to the playhead, middle-mouse panning, a scrollbar and clip right-click controls. Cue duplication and stable lyric-list scrolling when adding text.
- File → New / Load / Save, Windows file dialogs and shortcuts. Choose destinations for projects and subtitle exports.
- 4K compatibility encoding when browser H.264 is unavailable, and custom bitrate values such as 150 Mbps. MP4 export requires a selected folder and writes a single named output there.
- Conservative recovery from extreme repeated-token transcription loops, without changing normal repeated vocals or requested languages. Unrecoverable passages are flagged for manual review instead of shifting later lyrics.
- App version and author contacts in Settings, optional Buy Me a Coffee links, and a first-run popup that can be hidden.

Local Windows tests include real IN/OUT MP4 exports with audio, and an ocean 3D scene with both flat and spatial lyrics. Automatic transcription still needs human review; render speed depends on your hardware and project.

Install the Windows app for free from the [Microsoft Store](https://apps.microsoft.com/detail/9NF9JBG2PKHX). This GitHub release contains source code, not a separate installer: see the [README](https://github.com/jaydemks/phrasync/blob/main/README.md) for desktop and browser launch instructions.

GitHub and Store use the same version line. The matching 0.4.5.0 Store package was submitted for certification on October 6, 2026; the Store continues to offer the previous build until certification and rollout are complete.
