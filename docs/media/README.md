# README media

Public screenshots and the main demo referenced by the repository README belong in this directory.

## Reserved filenames

| File | Purpose | Recommendation |
| --- | --- | --- |
| `phrasync-mark.svg` | Logo used by the root README | Canonical brand mark; mirrored at `static/favicon.svg` |
| `phrasync-demo.mp4` | Main README video demo | H.264/AAC, 1080p or lower, web-optimized |
| `phrasync-demo-preview.gif` | Inline animated README preview | Short 640 px montage kept small enough to load quickly |
| `phrasync-social-preview.png` | GitHub and social-network link preview | 1280×640, solid background, below 1 MB |
| `editor-overview.png` | Complete editor | Generated by `scripts/capture_readme.py` |
| `kinetic-preview.png` | Live preview crop | Generated by `scripts/capture_readme.py` |
| `timeline-editor.png` | Timeline and sync crop | Generated by `scripts/capture_readme.py` |
| `local-ai-settings.png` | Local model settings | Generated by `scripts/capture_readme.py` |

The root README displays `phrasync-demo-preview.gif` inline and links it to the complete `phrasync-demo.mp4`. Repository MP4 files are not rendered as inline players by GitHub, so keep the GIF as the immediately visible preview. Start Phrasync, then run `.venv\Scripts\python.exe scripts\capture_readme.py` to refresh the screenshots. Before committing media, remove access tokens, private filesystem paths, and any source media you do not have permission to publish.

GitHub does not automatically use an image from the repository as its social preview. To install or replace the cover, open the repository **Settings**, find **Social preview**, choose **Edit**, then upload `phrasync-social-preview.png`. Keep the versioned file here in sync with the uploaded image.

GitHub accepts regular repository objects up to 100 MiB when pushed through Git. Files above that limit require Git LFS or a Release asset.
